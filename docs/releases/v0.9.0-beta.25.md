A sharper, smoother stream: Kasumi's network engine got a big fix.

- Fixed: above about 1 Mbps, video packets were lost inside the 3DS itself and had to be sent again (the RESENT/S number), which made higher bitrates stutter. The 3DS refuses the network buffer Kasumi asked for, and it was quietly left with a tiny one. Kasumi now finds the largest size the 3DS accepts. In testing, a 1.8 Mbps stream ran almost five minutes with a single resent packet
- Because of that, the default picture is sharper: Adaptive now streams about 1.3 Mbps instead of about 1 Mbps
- New Bitrate option, Sharp: about 1.8-2 Mbps for the most detail on strong Wi-Fi (3 bars, near the router). Steady 1 Mbps is still there for weak Wi-Fi or a phone hotspot
- Kasumi now uses the New 3DS's second CPU core for receiving video, so drawing, sound and your buttons no longer wait behind the network. If that core isn't available on your setup, everything works as before
- When the 3DS screen and the stream drift apart, Kasumi drops a frame where little is moving, so it's much less noticeable
- Fixed: when NVIDIA closed a game (for example after a while without input), Kasumi kept showing "reconnecting" forever. It now says the session was closed and lets you start again
- A game's own Bitrate option (game page, X) now shows what "Default" means, and launching a game that overrides it says so
