Calmer session ends, and a home for Kasumi players: the Kasumi Discord.

- When a game ends on NVIDIA's side after you've been playing a while (often because you quit from the game's own menu), Kasumi now shows a calm "Session ended" screen. It no longer blames idling or another device, and it no longer sends an error report for a normal end. Press A to play again or B to go back
- Kasumi now logs the reason NVIDIA gives for ending a session, so real problems are easier to find
- New: Settings > System > Kasumi Discord shows a QR code. Scan it with your phone to join the server (or visit discord.gg/K9Jy3t7YHE)
- After sending a diagnostic report, you can share its code on GitHub or in the Discord

Update from Settings > Updates, or install with FBI (Remote Install > Scan QR Code). Your login, library and settings are kept.
