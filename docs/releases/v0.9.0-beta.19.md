Launches that get you into the game, based on the diagnostic reports and on how the other OpenNOW clients handle NVIDIA's servers. Thank you to everyone sharing reports!

- Fixed: queues stuck on one number and dropped after 2 minutes ("queue abandoned"). NVIDIA now moves a waiting session between its servers (Frankfurt, London, Stockholm...), and Kasumi follows it there like the web client does, so the queue counts down again
- Fixed: "session limit" (HTTP 403) launches that beta.18 couldn't clear. Kasumi now uses one fixed client identity with NVIDIA, so it can see and close its own earlier sessions, and closes them on the rig that runs them
- New: when another GeForce NOW session is in the way, Kasumi asks. The same game can be resumed right here; a different one (maybe on your PC or phone) can be ended so your game starts
- New: when NVIDIA is still releasing a session, Kasumi waits and tries again every 45 seconds for up to 8 minutes, with a countdown, instead of failing (and instead of retrying so fast that NVIDIA rate limits you)
- Reconnecting after a drop now asks NVIDIA about the session first and resumes it when NVIDIA only paused it, so more drops end back in your game instead of "session ended"
- Queue: a dropped place in the queue is reported at once instead of after 30 seconds; busy servers get a gentler retry (up to about 2.5 minutes), and a game being updated on the rig counts as waiting, not an error
- If the last Standard session on this Wi-Fi was choppy, the next one starts in Weak / hotspot by itself (for that session only)
- A video freeze that lasts 12 seconds with Wi-Fi up now reconnects on its own
- Opt-in stats: each launch attempt is counted (reached the game, or why not), so we can see which fixes help. Numbers only, same switch as "Share performance stats"
- Fixed: after a game, pressing A sometimes said "Still working on the last request" two or three times (stats were being sent). A launch now always goes through on the first press
- When a new version is out, Kasumi now opens the update page by itself (press X for Later)
- Fixed two wrong values in the performance stats (sleep counted as a slow frame)
