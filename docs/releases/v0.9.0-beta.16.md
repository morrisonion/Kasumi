Help make Kasumi smoother and more reliable.

- New: after updating, Kasumi asks once: "Help improve Kasumi?" If you choose Share, it sends:
  - Problem reports: the log, on its own when something goes wrong (a crash, freeze, failed launch or a stream that can't reconnect), at most once per run and never during a game
  - Performance stats: after each session, a few anonymous numbers like ping, bitrate, frame rate, lost frames and reconnects. No log text and no addresses. These show which changes make streaming better for everyone
- If you choose No thanks, nothing is sent. Change either one anytime in Settings > System
- New: Settings > System > Send diagnostic report sends a report right now and shows a short code (like K7F-2QX) to mention in your bug report or message
- Reports never include your login; public IP addresses are shortened and a random install ID (not linked to your NVIDIA account) tells consoles apart. Reports are deleted after 30 days, stats after 90
- Kasumi now keeps the previous run's log (kasumi-diagnostic-previous.txt), so the log from a crash or freeze is no longer lost

Update from Settings > Updates, or install with FBI (Remote Install > Scan QR Code). Your login, library and settings are kept.
