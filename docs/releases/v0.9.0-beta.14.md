Fixes Server: Auto picking a far-away server.

- Fixed: on Auto, Kasumi could pick a server on another continent (like Texas from Europe), doubling the ping. Its measurement timed a network step the 3DS reports too early, so the numbers were noise. It now times real requests to each server, only measures the servers on your continent, and keeps NVIDIA's own choice unless another server is clearly faster
- Old measurements are thrown away, so the first launch after updating measures again (a few seconds)

Update from Settings > Updates, or install with FBI (Remote Install > Scan QR Code). Your login, library and settings are kept.
