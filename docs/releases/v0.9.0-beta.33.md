An experimental 60 fps mode.

- New (experimental): Settings > Picture > Frame rate: 60 fps. Twice the frames for smoother motion, at a slightly softer picture. It needs Screen mode: Wide 800. The 3DS can decode 60 fps in lighter games, but heavy ones (like DOOM Eternal) are right at its limit and can feel laggy, so Kasumi watches the decoder and switches that game back to 30 fps by itself when it can't keep up
- At 60 fps Kasumi asks NVIDIA for a lighter stream (1-1.5 Mbps, one reference frame) and to keep the frame rate steady instead of switching between 30 and 60
- Performance stats now record the frame rate, so we can see how 60 fps does on everyone's games and Wi-Fi. If you try it, a diagnostic report afterwards helps a lot

Update from Settings > Updates, or install with FBI (Remote Install > Scan QR Code). Your login, library and settings are kept.
