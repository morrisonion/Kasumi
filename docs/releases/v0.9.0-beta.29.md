A small update so problem reports get through.

- Send diagnostic report now tells you when a report couldn't be sent and why, and A sends it again. Before, it said "Sending" and then nothing
- If a report doesn't go through (weak Wi-Fi, a slow upload), Kasumi tries again with a smaller report on its own
- A report you send by hand no longer gets turned away while an automatic one is uploading
- Diagnostics: a failed send now logs where it stopped (finding the server, connecting, the secure handshake or the upload) and how long each step took

Update from Settings > Updates, or install with FBI (Remote Install > Scan QR Code). Your login, library and settings are kept.
