Fixes for launches that never got in.

- Fixed: in countries with a GeForce NOW partner (Chile, Brazil, Japan, Türkiye...), 0.9.0-beta.21 signed NVIDIA accounts in through the partner, which then showed an empty library and refused every game. The provider is now NVIDIA unless you pick your partner in Settings > Account. If this happened to you: Settings > Account > GeForce NOW provider > NVIDIA, then sign out and sign in again. Kasumi now also tells you when a partner login has no games or no access
- Fixed: some consoles were refused with "session limit per device" on every launch even with no game running anywhere. Kasumi now gets a fresh session slot by itself when that happens, instead of counting down for minutes
- Launching again and again in a row made NVIDIA refuse all launches for a minute (HTTP 429). Launches and "Try now" are now spaced out a little
- Fixed: the picture could freeze for good mid-game when NVIDIA lowered the stream's resolution on a weak connection (to sizes like 726x544). The 3DS decoder now accepts those sizes
- A connection that fails before the first picture (the rig answering slowly, or a reconnect NVIDIA refuses) is now retried automatically twice, instead of showing an error you had to retry yourself. The first connection to a new rig also gets a little longer to answer
- A launch NVIDIA answers with "timed out" (HTTP 408) is retried instead of failing
- Fixed: if the Wi-Fi dropped while Server: Auto was measuring, Kasumi could stop measuring that network for a week
- Fixed: pressing Leave twice cancelled the request that ends your session on NVIDIA's side, so the game could stay open there and block your next launch
- Ending a game now logs NVIDIA's answer, so diagnostic reports show whether the session really closed

Update from Settings > Updates, or install with FBI (Remote Install > Scan QR Code). Your login, library and settings are kept.
