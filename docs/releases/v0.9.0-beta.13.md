Playable on phone hotspots and weak Wi-Fi.

- New: Settings > Network > Connection type. "Weak / hotspot" streams at a steadier 0.6-1 Mbps, waits longer for lost packets and keeps a bigger buffer: a slightly softer picture with a little more delay, but far fewer freezes on mobile data or far-away Wi-Fi
- New: Settings > Network > Server. On Auto, Kasumi pings every GeForce NOW server and uses the fastest, measured again whenever you join a different Wi-Fi network (like a phone hotspot, whose address can make NVIDIA pick a far-away server). You can also pick a server yourself, or let NVIDIA choose as before
- Connection check now also pings every server and shows the fastest
- Fixed for everyone: lost video packets are now waited for according to your actual ping instead of a fixed 150 ms. On a slower connection, resent packets used to arrive just too late, freezing the picture until a new keyframe came
- Fixed: Kasumi no longer asks for the same lost packet several times, which made the server send it repeatedly on an already struggling connection
- Fixed: the UPDATE badge in the menus often didn't show. Kasumi forgot about a newer version after a restart and then waited up to 12 hours to check again; it now remembers it and checks every 4 hours

Update from Settings > Updates, or install with FBI (Remote Install > Scan QR Code). Your login, library and settings are kept.
