Help fix bugs faster with diagnostic reports.

- New: after updating, Kasumi asks once: "Help improve Kasumi?" If you choose Share, it sends its log to the developer on its own when something goes wrong (a crash, freeze, failed launch or a stream that can't reconnect), at most once per run and never during a game. If you choose No thanks, nothing is sent. Change it anytime in Settings > System > Share diagnostics
- New: Settings > System > Send diagnostic report sends a report right now and shows a short code (like K7F-2QX) to mention in your bug report or message
- A report holds the log of this run and the previous one, your settings (with a random install ID, not linked to your NVIDIA account) and the newest crash dump from the last 3 days. Your login is never included, public IP addresses are shortened, and reports are deleted after 30 days
- Kasumi now keeps the previous run's log (kasumi-diagnostic-previous.txt) instead of overwriting it, so the log from a crash or freeze is no longer lost

Update from Settings > Updates, or install with FBI (Remote Install > Scan QR Code). Your login, library and settings are kept.
